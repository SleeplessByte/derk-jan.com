# Project knowledge

This folder contains the output of questions and research, both by humans and agents.

Learnings that are specific to this repository: how the local setup behaves, which platform quirks cost time, and why features are built the way they are. General rules for working here are in [AGENTS.md](../AGENTS.md).

Read the file that matches your task before you start. Add to it when you learn something that the code and the git history do not show.

- [Local development](local-development.md): the dev server, builds, and how to verify a change without disturbing the user's setup.
- [Netlify](netlify.md): redirects, language negotiation and Netlify Forms.
- [Astro and CSS](astro-and-css.md): framework behaviour that was hard to find.
- [Gay Café 2026](gay-cafe-2026.md): the event invitation in `src/pages/events/2026-gay-cafe/`.
